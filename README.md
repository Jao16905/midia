# MidIA - O seu agente de gestão de conteúdo

## Sobre o MidiA

O MidIA é um agente de IA, construído utilizando a Langchain, Langgraph, FastAPI e NextJs, que busca facilitar a vida dos produtores de conteúdo. Seu propósito é além de simplesmente gerar roteiros simples, mas entregar uma estratégia de conteúdo robusta e completa.

## Tecnologias utilizadas

- NextJs
- Typescript
- FastAPI
- LangChain
- LangGraph
- LangSmith
- HikerAPI
- Tavily

## Instruções de uso

O projeto pretende ser simples. Você precisa apenas fazer o fork e instalar na sua máquina, após isso, você irá entrar em `/apps/frontend` e rodar o comando 

```bash
npm install
```

para instalar todas as dependências do frontend
